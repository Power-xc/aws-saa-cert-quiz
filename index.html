핵심 서비스 암기 노트

문제의 신호를 보고 가장 알맞은 AWS 서비스의 방향을 빠르게 잡는 표

이 표는 1차 분류용입니다. 문제에 비용, 지연 시간, 가용성 목표(RTO/RPO), 권한, 데이터 수명 주기 같은 추가 조건이 있으면 그 조건을 우선하세요.

저장소 선택

객체 저장, 정적 파일, 사실상 무제한 확장, 높은 내구성 Amazon S3
단일 EC2에 붙는 블록 스토리지(부팅·DB 볼륨) Amazon EBS
여러 Linux EC2·컨테이너가 공유하는 파일(NFS) Amazon EFS
Windows 파일 공유(SMB), Active Directory 통합 Amazon FSx for Windows
고성능 HPC·ML 파일 시스템 Amazon FSx for Lustre
접근 패턴을 모를 때 자동으로 계층 이동 S3 Intelligent-Tiering
거의 안 쓰는 장기 보관, 최저가 아카이브 S3 Glacier Deep Archive

컴퓨트 선택

이벤트 기반, 짧은 실행, 서버 관리 없음 AWS Lambda
서버 없이 컨테이너 실행(ECS·EKS 데이터 플레인) AWS Fargate
대량 장기 배치 작업 관리 AWS Batch
상시 예측 가능한 부하, 1~3년 약정으로 절감 Savings Plans / RI
중단 허용 가능한 내결함성 배치 Spot Instances
트래픽 급증에 맞춰 용량 자동 조절 EC2 Auto Scaling + ELB

데이터베이스 선택

관리형 관계형(OLTP), 표준 엔진 Amazon RDS
고성능 클라우드 네이티브 MySQL·PostgreSQL 호환 Amazon Aurora
키-값·문서, 밀리초 미만 지연, 서버리스 확장 Amazon DynamoDB
인메모리 캐시(세션·읽기 부하 완화) Amazon ElastiCache DynamoDB 캐시는 DAX
데이터 웨어하우스, 대규모 분석(OLAP) Amazon Redshift
관계형 읽기 확장은 read replica, 고가용성은 Multi-AZ 복제본 목적 구분

네트워킹과 콘텐츠 전송

정적·동적 콘텐츠 글로벌 캐시(CDN) Amazon CloudFront
비HTTP·고정 IP, 글로벌 네트워크로 지연 단축 AWS Global Accelerator
온프레미스 전용선, 일관된 대역폭·낮은 지연 AWS Direct Connect
인터넷 위 암호화 연결, 빠른 구축 Site-to-Site VPN
VPC에서 S3·DynamoDB로 프라이빗 접근(무료) Gateway VPC Endpoint
DNS, 라우팅 정책, 상태 확인 Amazon Route 53

로드 밸런싱

HTTP/HTTPS, 경로·호스트 기반 라우팅(L7) Application Load Balancer
TCP/UDP, 초고성능, 고정 IP, 극저지연(L4) Network Load Balancer
서드파티 방화벽·보안 어플라이언스 Gateway Load Balancer

보안과 자격 증명

EC2·Lambda가 다른 서비스 접근(액세스 키 금지) IAM Role
DB 비밀번호 등 비밀 저장·자동 교체 AWS Secrets Manager
저장 데이터 암호화 키 관리 AWS KMS
L7 웹 공격(SQL injection·XSS) 필터링 AWS WAF
DDoS 방어 AWS Shield
위협 탐지는 GuardDuty, S3 민감정보 탐지는 Macie 탐지 서비스 구분

복원력과 재해 복구(DR)

동기 복제 대기본으로 고가용성 확보(읽기 확장 아님) RDS Multi-AZ
비동기 복제로 읽기 부하 분산·확장 Read Replica
가장 저렴·긴 복구 시간, 백업만 보관 Backup & Restore
핵심 코어만 상시, 나머지는 확장 Pilot Light
축소판을 상시 가동해 대기 Warm Standby
최소 RTO/RPO, 다중 리전 상시 이중화 Active-Active

디커플링과 통합

비동기 작업 큐로 컴포넌트 분리 Amazon SQS
발행/구독 팬아웃 알림 Amazon SNS
서버리스 이벤트 버스, SaaS·서비스 이벤트 연결 Amazon EventBridge
실시간 스트리밍 데이터 수집·처리 Amazon Kinesis
여러 단계를 조율하는 워크플로(상태 머신) AWS Step Functions

비용 최적화

상시 예측 부하의 최대 절감 Savings Plans / RI
S3 객체를 규칙에 따라 저비용 계층으로 S3 Lifecycle 정책
NAT Gateway 데이터 처리 비용 회피 Gateway VPC Endpoint 사용
예산 초과 알림 AWS Budgets
비용 추세 분석·리포트 Cost Explorer / CUR

공부 방향: SAA-C03은 서비스 하나를 외우기보다 "요구 사항의 신호(비용·지연·가용성·보안·운영 부담)"에 가장 맞는 서비스를 고르는 시험입니다. 오답 선택지도 왜 틀렸는지 해설에서 함께 짚어 두었으니 비교하며 익히세요.

기기 간 동기화

한 기기에서 내보낸 코드를 다른 기기에서 가져오면 오답노트·학습 기록이 합쳐집니다. 로그인 없이 동작합니다.

이 기기 기록 내보내기

다른 기기 기록 가져오기
