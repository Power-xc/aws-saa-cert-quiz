# AWS SAA Cert Quiz

> AWS Certified Solutions Architect – Associate(SAA-C03) 대비 문제은행 웹앱

## 소개

브라우저에서 바로 실행되는 프레임워크 없는 정적 웹앱입니다. SAA-C03 시험의 네
개 도메인(보안·복원력·고성능·비용) 문제를 학습 모드와 시험 모드로 풀 수 있고,
학습 기록은 브라우저에 저장되어 오답노트와 진행 이어 풀기로 이어집니다. 백엔드와
로그인 없이 동작하며, 학습 기록은 코드나 링크로 다른 기기에 옮길 수 있습니다.

문제는 공식 시험 가이드의 도메인·과제(task statement)를 기준으로 직접 작성한
시나리오형 문항이며, 정답과 함께 오답 선택지가 왜 틀렸는지도 해설에 담았습니다.

데모: https://power-xc.github.io/aws-saa-cert-quiz/

## 기능

- 네 개의 도메인 문제은행(총 600문항): 보안 180문항, 복원력 156문항, 고성능 144문항, 비용 120문항
- 모의시험: 도메인 비율(30/26/24/20%)로 65문항을 뽑아 130분 타이머로 풀고, 도메인별 점수와 최근 점수를 기록
- 학습 모드: 한 문제씩 즉시 채점하고 해설 확인
- 시험 모드: 전체를 푼 뒤 일괄 채점하고 채점표로 검토
- 오답노트: 최근에 틀린 문항만 모아 다시 풀기
- 단일 정답과 복수 정답(multiple response) 문항 모두 지원
- 한국어 문제에 시험 영문 용어 병기(AWS 한국어 문서 표기 기준), 핵심 서비스 암기 노트와 한/영 용어 대조 제공
- 진행 상황 이어 풀기와 누적 학습 통계
- 기기 간 동기화: 코드/링크로 학습 기록 이동(서버 불필요)
- 라이트·다크 테마와 키보드 단축키

## 시작하기

### 요구 사항

- Node.js 22 이상

### 설치와 실행

```bash
npm install
npm run dev
```

개발 서버가 안내하는 주소를 브라우저에서 엽니다.

### 스크립트

| 명령                | 설명                              |
| ------------------- | --------------------------------- |
| `npm run dev`       | 개발 서버 실행                    |
| `npm run build`     | 타입 체크 후 정적 파일 빌드(dist) |
| `npm run preview`   | 빌드 결과 미리보기                |
| `npm run lint`      | ESLint 검사                       |
| `npm run typecheck` | 타입 체크                         |
| `npm test`          | 단위 테스트 실행                  |

### 문제 데이터

문제은행은 `public/data/*.json`에 도메인별로 있으며, 각 항목은 다음 형태를
따릅니다.

```json
{
  "id": 1,
  "multi": false,
  "question": { "ko": "질문" },
  "choices": [{ "key": "A", "ko": "보기" }],
  "answer": ["C"],
  "explanation": { "ko": "해설" }
}
```

`multi`가 `true`이면 정답이 둘 이상인 복수 정답 문항입니다.
